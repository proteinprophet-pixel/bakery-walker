# 🥐 빵지순례 & 도보 다이어트 (Bakery Walker)

> **카카오맵 MCP 기반 모바일 뚜벅이 베이커리 투어 & 칼로리 밸런스 플래너**

## ✨ 주요 기능
- 📍 **모바일 위치(GPS) 및 주요 핫플레이스 탐색** (성수동, 연남·홍대, 익선·을지로, 한남동, 판교 등)
- 🥐 **디저트 칼로리 바구니** (소금빵, 앙버터, 딸기케이크, 크루아상, 베이글 등)
- ⚖️ **칼로리 밸런스 위젯** (먹은 칼로리 ↔ 목표 도보 시간 & 거리 계산)
- 🗺️ **스마트 3단계 뚜벅이 코스 자동 생성** (베이커리 성지 ➡️ 소화 산책길 ➡️ 감성 카페)
- 🟡 **카카오맵 모바일 길찾기 딥링크 연동**
